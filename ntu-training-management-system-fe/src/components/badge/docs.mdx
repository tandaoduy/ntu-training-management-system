# Badge Component Documentation

## Overview

A lightweight badge component for status labels, tags, categories, roles, and compact metadata. Supports color variants, sizes, optional icons, status dots, and rounded pill or rounded rectangle shapes.

## Features

✅ **Variants**: default, success, warning, danger, info, neutral  
✅ **Sizes**: sm, md, lg  
✅ **Status Dot**: Optional colored dot  
✅ **Icon Slot**: Optional icon before text  
✅ **Shape Control**: Pill or rounded rectangle  
✅ **Tailwind CSS**: Fully styled with Tailwind  
✅ **TypeScript**: Full type safety  

## Installation

The badge component is ready to use from `@/components/badge`.

## Usage

```tsx
import { Badge } from '@/components/badge';

export const MyComponent = () => {
  return (
    <div className="flex gap-2">
      <Badge variant="success">Active</Badge>
      <Badge variant="warning">Pending</Badge>
      <Badge variant="danger">Blocked</Badge>
    </div>
  );
};
```

## API Reference

### Badge Props

```typescript
interface BadgeProps {
  children: ReactNode;
  variant?: 'default' | 'success' | 'warning' | 'danger' | 'info' | 'neutral';
  size?: 'sm' | 'md' | 'lg';
  icon?: ReactNode;
  dot?: boolean;
  pill?: boolean;
  className?: string;
}
```

Default values:

- `variant`: `'default'`
- `size`: `'md'`
- `dot`: `false`
- `pill`: `true`

## Styling

The component uses Tailwind CSS with soft background colors, readable text colors, and inset ring borders.

- **Default**: Blue
- **Success**: Green
- **Warning**: Yellow
- **Danger**: Red
- **Info**: Cyan
- **Neutral**: Gray

## Customization

To customize colors, edit `variantClasses` and `dotClasses` in `Badge.tsx`:

```tsx
const variantClasses = {
  default: 'bg-blue-50 text-blue-700 ring-blue-600/20',
  success: 'bg-green-50 text-green-700 ring-green-600/20',
  warning: 'bg-yellow-50 text-yellow-800 ring-yellow-600/20',
  danger: 'bg-red-50 text-red-700 ring-red-600/20',
  info: 'bg-cyan-50 text-cyan-700 ring-cyan-600/20',
  neutral: 'bg-gray-100 text-gray-700 ring-gray-600/20',
};
```
