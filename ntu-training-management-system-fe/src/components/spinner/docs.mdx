# Spinner Component Documentation

## Overview

A small loading spinner component for async states, submit buttons, table loading rows, and page-level loading indicators. Supports sizes, color variants, and accessible loading labels.

## Features

✅ **Sizes**: sm, md, lg, xl  
✅ **Variants**: primary, secondary, white, success, danger  
✅ **Accessible**: Uses `role="status"` and screen-reader text  
✅ **Tailwind CSS**: Fully styled with Tailwind  
✅ **TypeScript**: Full type safety  

## Installation

The spinner component is ready to use from `@/components/spinner`.

## Usage

```tsx
import { Spinner } from '@/components/spinner';

export const MyComponent = () => {
  return <Spinner />;
};
```

## API Reference

### Spinner Props

```typescript
interface SpinnerProps {
  size?: 'sm' | 'md' | 'lg' | 'xl';
  variant?: 'primary' | 'secondary' | 'white' | 'success' | 'danger';
  label?: string;
  className?: string;
}
```

Default values:

- `size`: `'md'`
- `variant`: `'primary'`
- `label`: `'Loading'`

## Styling

The spinner is built with a circular border and Tailwind `animate-spin`.

- **Primary**: Blue
- **Secondary**: Gray
- **White**: For dark or colored backgrounds
- **Success**: Green
- **Danger**: Red

## Customization

To customize sizes, edit `sizeClasses` in `Spinner.tsx`:

```tsx
const sizeClasses = {
  sm: 'h-4 w-4 border-2',
  md: 'h-6 w-6 border-2',
  lg: 'h-8 w-8 border-2',
  xl: 'h-12 w-12 border-4',
};
```

To customize colors, edit `variantClasses` in `Spinner.tsx`:

```tsx
const variantClasses = {
  primary: 'border-blue-200 border-t-blue-600',
  secondary: 'border-gray-200 border-t-gray-700',
  white: 'border-white/40 border-t-white',
  success: 'border-green-200 border-t-green-600',
  danger: 'border-red-200 border-t-red-600',
};
```
